# Café Coado - Python + Flask

## Como rodar
1. Instale o Flask: pip install flask
2. Na pasta do projeto, rode: python app.py
3. Abra no navegador: http://127.0.0.1:5000

## Páginas
- / -> Início + Cardápio
- /sobre -> Sobre
- /local -> Local
